## WHY｜讓 PRD 變成可感受的體驗

文字 PRD 無法直接驗證體驗。選對呈現方式與工具，是用最少力氣回答眼前需要驗證的問題。

## 完整度與工具對照

| 層級 | 呈現方式 | 可考慮工具 |
| --- | --- | --- |
| 1 | 文字流程 | ChatGPT、Claude |
| 2 | Wireframe | ChatGPT、Claude、Gemini |
| 3 | 可點擊原型 | Gemini / AI Studio、v0 |
| 4 | 可運作 Demo | Cursor、Claude Code |
| 5 | 可部署產品 | Cursor / Claude Code、GitHub Pages、Vercel、Netlify |

## WHAT｜萬用提示詞

```text
以下是我們的 PRD v2：【貼上 PRD】
今天決定做到的完整度是：【填入層級】。
請先回覆你對需求的理解與生成計畫；等我確認後才開始製作。
```

## 建議產出

符合選定完整度的流程、原型、Demo 或可部署產品，以及使用工具與下一步清單。
