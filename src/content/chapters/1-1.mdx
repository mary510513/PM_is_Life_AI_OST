## WHY｜為什麼要先找到問題

- 沒有先定義問題，AI 只會順著假設走，PRD 與 Demo 容易建立在錯誤基礎上。
- 先花 10–15 分鐘想清楚問題，後面的工作才不會白做。

## HOW｜5 個方法

| 方法 | 用途 |
| --- | --- |
| Design Thinking | 從使用者與情境出發。 |
| 5 Whys | 一層層追問問題背後的原因。 |
| JTBD | 理解使用者真正想完成的任務。 |
| 問題樹 | 拆解主要問題與可能原因。 |
| Feynman Technique | 用自己的話確認是否真的理解問題。 |

## WHAT｜提示詞

```text
我目前有一個模糊的想法：【填入想法】
請不要直接提出解法，先用提問幫我釐清：誰遇到問題、在什麼情境下、目前怎麼處理、造成什麼影響，以及還缺少哪些資訊。請一次問一個問題。
```

## 建議產出

一句話問題描述、目標使用者、使用情境、初步問題假設與尚未確認的問題。
